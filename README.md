# Fake AI Analysis

An AI-powered application designed to analyze digital content and identify potentially fake or manipulated media. It helps users examine suspicious content and understand whether it may be authentic or AI-generated.

## Features
- AI-powered fake content analysis
- Simple and user-friendly interface
- Fast analysis and results
- Backend API integration
- Easy-to-use web application

## Tech Stack
- **Frontend:** React
- **Backend:** Python, FastAPI
- **AI/ML:** AI-based media analysis
- **API:** REST API

## Getting Started

### 1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

### 2. Backend Setup
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
